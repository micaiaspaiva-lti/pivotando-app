# Pivotando — app

**Juntos, viramos o jogo.** Desafios de inovação colaborativa da LTI.

- **Sistema:** https://micaiaspaiva-lti.github.io/pivotando-app/ (exige conta Google **@lti.net.br**)
- **Demonstração** (dados fictícios, sem login): https://micaiaspaiva-lti.github.io/pivotando-app/demo/

Este repositório contém **apenas** a casca instalável (PWA) que abre o Web App do Google Apps Script em tela cheia, e a página da demonstração. O sistema em si, os dados e as regras de acesso ficam no Google, com acesso restrito ao domínio. O código-fonte está em um repositório privado.

## Instalar como app

- **Chrome / Edge (computador):** abra o link do sistema e clique no ícone de instalar na barra de endereço.
- **Android (Chrome):** menu ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartilhar → *Adicionar à Tela de Início*.
